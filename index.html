オーナーの3つの悩み

「時間がない」「お金がない」「ポータルをやめたい」に、こう答えます。

時間がない

朝から晩まで施術に立っている。HPの更新も広告の調整も、閉店後の残り時間では手が回らない。

当社の答え

運用はAIと当社が回します。広告の日次監視、LPの更新、レポートまで。HP更新・広告・レポートは当社から届きます。オーナーがやるのは、届いたものを見ることと、施術後の1行カルテだけ。気になったことはいつでもLINEで相談できます。

お金がない

広告に月10万円は出せない。ポータルの掲載料だけで手一杯で、売上が上がっても手元に残らない。

当社の答え

広告費は月3.5万円以内で設計します。自店もこの金額で回しています。事例価格は初期費用0円・最初の3ヶ月は月額3万円(4ヶ月目から通常の月額5万円)。ポータル1社分より安く始められます。

ポータルをやめて、自分のお客様を積み上げたい

やめたいが、やめた翌月から新規が止まるのが怖い。クーポンで来る客は、次もクーポンの店へ行く。

当社の答え

HP・LP・定着導線を、店の資産として残します。90日で自店経由の新規と再来率を数字で見てから、ポータルを減らすかどうかを決められます。

売上が右肩上がりになる型

やることは4つに絞る。だから、時間がなくても回る。

美容室の売上はこの4つの数字で決まります。あれもこれもではなく、この4つだけを100と0に近づける。当社はこの型で自店を運営し、同じ型を納品先の店に入れます。

集客100月の新規目標を、広告で毎月100%埋める
リピート100初回のお客様を、4週間以内の再来へ100%つなぐ設計
リクルート100必要な席を埋める人を、求人サイトに頼らず確保する
離職0人が辞めない距離感と、辞めてもお客様が残る仕組み
新規が積み上がり、辞めず、残る。だから売上は右肩上がりになる。自店では月商100万円 → 150万円、リピート率60% → 90%以上

ポータル依存との違い

やめたいのにやめられない。その構造ごと変える。

ポータルは新規を連れてきますが、お客様はポータルのものです。掲載を切れば翌月から来なくなる。だからやめられない。当社は、お客様が店に残る形で新規を入れます。

常連づくりの中身

5つの層を、一式で入れる。

広告だけなら新規は来ても残らず、HPだけなら誰にも見つかりません。次回予約を口頭で聞くだけでは、誰も入れません。口コミが増えなければ、新規はまた入りにくくなる。5層を同時に動かして初めて、店にお客様が積み上がります。

01ホームページ自社予約導線つき。制作・公開・保守ポータルを経由しない予約の受け皿
02ランディングページ初回オファー専用。口コミ・残り枠・受付期限を表示広告から予約への転換
03地域広告店から1.5km・年齢層を絞ったMeta広告。制作から日次運用まで新規を安定して入れる
04定着導線4週リタッチ価格 / 次回予約割引 / LINE公式 / 1行カルテ / 次回予約の告知POP / カウンセリングシート初回のお客様を、通い続けるお客様に
05店内と口コミGoogleマップの添削と口コミ導線 / 季節の単価アップPOP / 受付から会計までのオペレーション添削常連が口コミを書き、次の新規を連れてくる

なぜ「研究所」なのか

去年の正解が今年の正解ではない早い時代。だから研究し続ける。

広告の出し方も、お客様の探し方も、現場への落とし込み方も、1年で変わります。当社は自店を実験場にして、効いたものだけを納品先の店に入れ、効かなくなったものは入れ替えます。納品して終わりではなく、更新し続ける契約です。

新しい広告の型、初回オファー、LINEの使い方。まずTerminal#10で回して数字を見てから、店に入れます。

効いたものだけ納品する

月末の1枚レポートで、何が効いて何が効かなかったかを共有。翌月の打ち手はそこから決めます。

ゆとりを数字で測る

目指すのは売上だけではなく、オーナーが運営に使う時間と、ポータルに払う費用が減ること。この2つを毎月見ます。

代表から

美容師が、動いた分だけの職業でなくなるように。

美容師は、髪を切っている時間しかお金になりませんでした。経営も、集客も、現場が終わった後の残り時間でやるしかなかった。私自身、麻布十番で10年そうやってきました。

AIを店に入れて変わったのは、時間が減ったことより「できることが増えた」ことです。HPも広告もレポートも自分の店で回せるようになり、美容師が経営者としての判断に時間を使えるようになった。

個人サロンが、ポータルに頼らず、自分の店にお客様を積み上げて、美容師がのびのびと仕事を続けられる。その土台を整えるのが、当社の仕事です。
